# 塔防游戏服务器开发记录

## 技术栈

| 模块     | 技术选型                              |
| -------- | ------------------------------------- |
| Web API  | ASP.NET Core Minimal API (.NET 8)     |
| 数据库   | SQLite（开发）-> MySQL（上线）         |
| ORM      | Dapper                                |
| 认证     | JWT Token                             |
| 实时通信 | LiteNetLib（可靠有序传输）             |
| 帧同步   | 自研（操作攒批 + 广播）                |
| 协议     | protobuf（UDP + HTTP 统一）           |

## 架构总览

```
客户端 (Unity, HybridCLR 热更 + Addressables)
├── HttpMgr ───> LoginServer (ASP.NET Core) ── 账号/养成数据/JWT
└── NetMgr ────> GameServer (LiteNetLib) ──── 房间/匹配/帧同步/结算

LoginServer: Minimal API + SQLite/Dapper + 注册登录 + 玩家数据读写 + JWT
GameServer:  LiteNetLib + 帧同步引擎(操作转发) + 结算入账(直连 SQLite)
```

- [x] 前后端 proto 联调验证

### 开发约定（必须遵守）

- **proto 位置**：`Server/wgame-server/Proto/*.proto`（唯一协议源），改后跑 `DataTables/gen_proto.sh` 生成客户端代码（或 Unity ToolBox "导 Proto"）；服务器侧 build 时 Grpc.Tools 自动生成
- **命名**：`XxxReq` ↔ `XxxResp` 成对，主动推送用 `XxxPush`；错误码 ErrorCode 枚举固定放 field 1，业务字段从 field 2 往后排
- **字段号即契约**：开发期无线上流量可回收/调整，上线后只能追加
- **MsgType/ErrorCode**：在 net_common.proto 追加枚举值
- **HTTP URL 共享**：`Proto/NetApi.cs` 手写常量；字段名 `X` + 注释 `// POST|GET`，导 Proto 后自动补全 ApiRegistry.RegisterAll
- **传输/协议分层**：NetMgr（Framework/AOT）只做 byte[] 收发；NetMsgHandler/Game 层做协议解析（依赖单向）

## 阶段 5：帧同步（已完成）

双人操作经服务器转发，双端确定性执行。

- [x] PlayerInput/FrameData 协议，服务器 50ms 攒批广播（空帧也发保帧号连续）
- [x] 客户端 FrameSyncMgr：缓冲 2 帧防抖动、墙钟驱动、网络突发积压显式追赶（超 6 帧每周期多消费 2 帧）
- [x] 确定性逻辑层 BattleLogic（纯 C# 无 Unity）+ 表现层 BattleTD 分离
- [x] 定点数 Fix（Q16.16 64 位，±1.4e14）+ 确定性随机 XRng（xorshift64*）
- [x] 双端状态哈希逐帧校验一致，真机联调通过

### 确定性纪律（逻辑层禁用）

| 禁用              | 替代                       |
| ----------------- | -------------------------- |
| float/double      | 定点数 Fix（FromInt/FromDouble 常量构造） |
| UnityEngine.Random / System.Random | XRng + 同步种子 |
| Time.deltaTime    | 固定逻辑帧（50ms）         |
| Dictionary 遍历   | List / 有序结构            |
| Physics           | 自研或不用                 |

其他要点：业务小数常量用 `Fix.FromDouble(0.07)`（编译期位模式唯一，仅限初始化）；概率用 `Chance(pct)/ChanceBp(bp)`（万分比整数比较）；配置进逻辑层优先 int + 单位语义（帧/毫秒/万分比）。

### 真机踩坑记录（重要）

- **URP 材质**：CreatePrimitive 默认材质真机粉色；shader 只进 bundle 时 `Shader.Find` 返回 null，兜底链：URP Lit -> 克隆管线 defaultMaterial -> Sprites/Default；URP 颜色属性是 `_BaseColor`
- **BoxCollider 被裁**：HybridCLR link.xml 扫不到 native 按类名添加的组件，独立 `Assets/link.xml` preserve `UnityEngine.PhysicsModule`
- **热更脚本挂载规则**：热更脚本只能挂 Addressables/AB 场景预制体，Build Settings 主包场景绝不能挂
